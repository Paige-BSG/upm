This is the public documentation for **UPM**, an AI-native data-service ops control
plane: an open-source project to manage databases and middleware on Kubernetes, with an
in-product agent as a first-class operator. Use the left navigation to read about the
project's intent, its current status, and its intended architecture, or jump to the
[contribution guide](/contributing/workflow) to get involved.

> Status: this is early work. The public repository currently holds this documentation and
> the agent LLM wiki, but **not yet product source code**. Treat the architecture and
> roadmap pages as the intended direction, not a description of a shipped product.
