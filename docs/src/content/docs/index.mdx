This is the public documentation for **UPM**, an open-source project to manage
databases and middleware on Kubernetes. Use the left navigation to read about the
project's intent, its current status, and how it is architected, or jump to the
[contribution guide](/contributing/workflow) to get involved.

> Status: the public repository currently holds this documentation and the agent LLM
> wiki, but **not yet product source code**. Product code is being refactored and
> released; treat the architecture and roadmap pages as the intended direction, not a
> description of a shipped product.
