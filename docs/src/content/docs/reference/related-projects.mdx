UPM is not developed in isolation. Two public projects define its reference and its
comparison.

## upmio

- Repository: [https://github.com/upmio](https://github.com/upmio)
- Role: **reference implementation**. UPM is a thorough refactor of upmio, released as
  open source — not a fork of a branch. The earlier open-source codebase is reference
  material.

## KubeBlocks

- Repository: [https://github.com/apecloud/kubeblocks](https://github.com/apecloud/kubeblocks)
- Role: **comparison baseline**. KubeBlocks gates its advanced features behind a paid
  tier, which is contrary to the open-source spirit UPM follows. UPM keeps its
  fundamentals open. Use KubeBlocks only as a neutral point of comparison. The LLM wiki
  documents it with first-hand sources and neutral phrasing.

## The documentation stack

- **Nimbus Docs** (`cloudflare/nimbus`) — the docs framework this site is built on. It is
  a meta-tool of this repository, not UPM tech stack, and is described in the LLM wiki.
